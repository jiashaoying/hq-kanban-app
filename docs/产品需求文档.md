---

## 一、产品概述

### 1.1 产品背景

投资者与金融从业者需要快速掌握大盘整体走势。现有行情工具（券商 App、财经网站）信息密度高、操作路径深，查看三大市场（A 股、港股、美股）核心指数往往需要多次切换页面。本项目旨在提供一个**轻量、常驻、一屏尽览**的大盘行情看板。

### 1.2 产品定位

一款跨平台（macOS / iOS）的**大盘指数行情看板工具**，聚焦「核心指数 + 实时刷新 + 极速查看详情」三件事，不做个股交易、不做资讯聚合，保持轻量纯粹。

### 1.3 产品目标

- 打开即看：启动后 1 秒内呈现全部核心指数的最新行情
- 一屏尽览：A 股 / 港股 / 美股三大市场分组展示，无需滚动切换多个页面
- 点开即查：点击任意指数，一步进入分时图与 K 线详情
- 双端一致：桌面与移动端体验一致，数据同源

## 二、目标用户与使用场景

### 2.1 目标用户

| 用户群体 | 典型特征 | 核心诉求 |
|---|---|---|
| 个人投资者 | 日常关注大盘，持仓以 A 股为主，兼顾港美 | 盘中随时扫一眼大盘，快速判断市场情绪 |
| 金融从业者 | 交易员、研究员、行政人员，需要常驻行情 | 桌面端常驻小窗，不抢占工作屏幕 |
| 移动端用户 | 通勤、外出时用手机查看行情 | 打开快、流量省、界面清晰 |

### 2.2 核心使用场景

1. **盘中监控**（高频）：桌面看板常驻屏幕角落，每 3 秒自动刷新，用户无需任何操作即可掌握大盘实时涨跌
2. **快速详情查看**（中频）：看到某指数异动（如上证跳水），点击卡片 → 查看分时图判断全天走势 → 切换日K看近期位置 → 返回看板，全程 3 次点击以内
3. **盘后复盘**（低频）：切换周K/月K查看指数中长期趋势
4. **移动端碎片化查看**（中频）：手机打开 App，首页即行情，详情页大图表适配触屏

## 三、功能需求

### 3.1 功能架构

```
大盘行情看板
├── F1 行情看板（首页）
│   ├── F1.1 指数卡片列表（三市场分组）
│   ├── F1.2 自动轮询刷新
│   └── F1.3 手动刷新
├── F2 指数详情页
│   ├── F2.1 实时报价头部
│   ├── F2.2 分时图（双轴 + 成交量）
│   ├── F2.3 K线图（日K / 周K / 月K）
│   └── F2.4 导航返回
└── F3 系统能力
    ├── F3.1 跨平台适配
    └── F3.2 数据获取与容错
```

### 3.2 F1 行情看板（首页）

#### F1.1 指数卡片列表

- 按 A 股、港股、美股三个市场分组展示，每组带分组标题与分隔线
- 每个指数渲染为一张卡片，包含：指数名称、当前点位、涨跌额、涨跌幅、成交量、成交额
- **覆盖指数（11 个）**：
  - A 股：上证指数、深证成指、创业板指、沪深300、上证50、中证500
  - 港股：恒生指数、恒生科技指数
  - 美股：道琼斯、纳斯达克、标普500
- **配色规则（中国市场惯例）**：上涨红色、下跌绿色、平盘灰色；卡片左边框颜色随涨跌变化
- 卡片可点击，点击进入该指数详情页（F2）

#### F1.2 自动轮询刷新

- 桌面端每 3 秒自动刷新一次；移动端每 15 秒（兼顾流量与电量）
- 应用切后台（visibilitychange）时暂停轮询，回到前台立即刷新并恢复轮询
- 刷新期间显示更新时间，数据无变化时界面不闪烁

#### F1.3 手动刷新

- 标题栏提供「刷新」按钮，点击立即触发一次数据拉取

### 3.3 F2 指数详情页

#### F2.1 实时报价头部

- 显示：指数名称、代码、返回按钮、当前点位（大字号）、涨跌额、涨跌幅
- 报价数据与看板同源（复用首页轮询），进入详情页后价格持续自动更新，无需额外请求

#### F2.2 分时图

- **主图**：当日分钟级价格走势（Area 面积图），红涨绿跌（相对昨收），面积渐变填充
- **双纵坐标轴**：左侧为指数点位（2 位小数），右侧为涨跌幅百分比（`+0.39%` / `0.00%` / `-1.23%` 格式，正负号均显示），两轴刻度严格对齐
- **昨收基准线**：虚线恒居垂直正中，左轴对应昨收点位、右轴对应 0.00%
- **成交量副图**：主图下方独立区域（高度比约 4:1），分钟成交量柱，涨红跌绿
- **时间轴**：预留全天宽度（A 股 09:30–15:00），走势线从左向右生长；午休时段（11:30–13:00）不产生空洞
- **数据刷新**：每 15 秒自动轮询，仅更新数据不重置用户缩放/平移视野
- **十字光标**：悬停时左轴显示该点指数、右轴显示该点涨跌幅
- **空态降级**：市场休市或数据不足时显示「暂无分时数据（市场休市中）」，不白屏

#### F2.3 K线图

- 支持日K / 周K / 月K 三个周期切换（Tab），默认日K
- **主图**：蜡烛图（红涨 #ef232a / 绿跌 #14b143，含影线）+ MA5 / MA10 / MA20 均线（黄/蓝/紫，左上角图例）
- **成交量副图**：独立区域，量柱随当日涨跌着色
- **数据缓存**：同周期切换不重复请求（60 秒 TTL 缓存），平衡时效与流量
- 默认加载约 320 根 K 线（约一年半日K）
- **空态/错误降级**：请求失败显示「K线加载失败 + 点击重试」；无数据显示空态

#### F2.4 导航返回

- 详情页头部返回按钮；桌面端支持 ESC 键返回
- 返回看板后看板状态保持，滚动体验连续

### 3.4 F3 系统能力

#### F3.1 跨平台适配

- macOS：自定义标题栏（可拖动窗口）、最小化/关闭按钮；窗口默认 900×680
- iOS：适配安全区（刘海/底部 Home 指示条）；图表容器固定高度，整页滚动，避免触摸手势冲突
- 移动端轮询间隔自动放宽至 15 秒

#### F3.2 数据获取与容错

- 所有外部请求由 Rust 后端发起（无浏览器 CORS 限制），复用进程级 HTTP 连接池（连接超时 5s / 总超时 10s）
- 输入参数白名单校验（指数代码、K线周期、数量上限），防注入
- 网络失败静默容错：保留上一次数据，不弹窗打扰；详情页图表区显示友好错误文案与重试入口

## 四、非功能需求

| 维度 | 要求 |
|---|---|
| 性能 | 首屏 1 秒内渲染；分时图 242 点全量刷新 < 5ms；图表交互 60fps |
| 体积 | 首屏 JS 增量控制（图表库按需异步加载，不进入主包） |
| 可靠性 | 数据源异常不崩溃、不白屏，全部降级为空态/错误态 |
| 安全 | 后端 IPC 命令输入校验；HTTPS 数据源；无用户数据收集 |
| 兼容 | macOS（Apple Silicon）、iOS 14.0+；iOS 构建链含 wry 补丁（NSBundle 崩溃修复） |
| 可维护 | 前后端数据契约集中定义（snake_case 对齐）；图表逻辑封闭在独立组件内 |

## 五、数据源与技术架构

### 5.1 数据源（腾讯财经，免鉴权）

| 接口 | 用途 | 格式 |
|---|---|---|
| `qt.gtimg.cn/q={codes}` | 实时指数报价（看板+详情头部） | GBK 文本，`~` 分隔字段 |
| `web.ifzq.gtimg.cn/appstock/app/minute/query` | 分时数据 | UTF-8 JSON |
| `web.ifzq.gtimg.cn/appstock/app/fqkline/get` | 日K/周K/月K | UTF-8 JSON |

注意：指数代码在两类接口间存在前缀差异（`r_hkHSI` → `hkHSI`），由后端统一归一化；美股分时无累计额列，休市数据稀疏需前端降级。

### 5.2 技术架构

| 层 | 技术 | 说明 |
|---|---|---|
| 前端 | Vue 3 + TypeScript + Vite 8 + Tailwind CSS 4 | 组合式 API，无路由（状态切换两视图） |
| 图表 | lightweight-charts v5 | 多 pane 布局（主图+量图物理隔离）、双轴对称缩放 |
| 后端 | Rust + Tauri v2 + reqwest + serde_json | 数据抓取/解析/校验全部在 Rust 侧，前端只消费干净类型 |
| 平台 | Tauri v2（WKWebView） | macOS / iOS 双端；iOS 含 wry patch |

## 七、风险与约束

| 风险 | 等级 | 应对 |
|---|---|---|
| 腾讯接口为非官方公开接口，字段格式可能变更 | 高 | 解析集中于 Rust 层单模块，字段索引容错（parse_f64 静默降级）；数据结构变更只需改一处 |
| 港美指数分时数据稀疏/休市无数据 | 中 | 前端空态降级，不影响核心 A 股场景 |
| iOS 构建链敏感（wry patch 共存） | 中 | 严格隔离补丁范围；Rust 改动限于纯 HTTP 逻辑 |
| 移动端流量与电量 | 低 | 移动端 15s 轮询、切后台暂停、K线 TTL 缓存 |

## 八、原型设计

### 8.1 原型文件与打开方式

- **文件位置**：`docs/prototype/index.html`（随仓库提交）
- **打开方式**：双击文件（或拖入浏览器）即可，无需构建、无需本地服务器
- **自包含性**：内联 CSS/JS，零外部依赖、零网络请求，图片全部由内联 SVG/CSS 绘制，离线可用
- **原型性质**：高保真交互原型，使用静态 mock 数据（演示快照：截至 10:47，上证指数 3942.54 −0.94%），用于评审视觉风格与交互流；界面元素上的小角标（F1.1/F2.2 等）对应本文第三章功能编号，悬停可见说明，页面底部附完整编号图例

### 8.4 交互说明表

| 操作 | 响应 |
|---|---|
| 看板点击任意指数卡片 | 切换到该指数详情页（hash 路由 `#/detail/{code}`，支持浏览器前进/后退） |
| 详情页点击「←」返回按钮 | 返回看板，看板状态保持 |
| 详情页按 ESC 键 | 同返回按钮（桌面端行为，F2.4） |
| 点击 Tab 分时 / 日K / 周K / 月K | 切换下方图表：分时（折线+面积+量柱）↔ K线（蜡烛+MA+量柱）；周K / 月K 柱数递减；原型以内存缓存模拟 F2.3「同周期不重复请求」的 60s TTL 缓存语义 |
| 卡片 / 返回按钮 / Tab 悬停 | 高亮描边 + 轻微上浮（过渡动画），Tab 文字变亮 |
| 分时图悬停 | 十字光标吸附最近分钟点：左轴气泡显示该点指数、右轴显示该点涨跌幅（带正负号）、下方显示时间（F2.2） |
| K线图悬停 | 竖线吸附最近蜡烛：右轴气泡跟随鼠标反算价格、下方显示日期（F2.3） |
| 点击「刷新」（F1.3） | 蓝色脉动指示约 0.9s + 更新时间步进（模拟一次数据拉取） |
| 悬停「F1.x / F2.x」角标 | 浮层显示该界面元素对应的 PRD 功能编号说明 |
| 浏览器窗口缩放 | 图表按容器宽度自适应重绘；看板卡片在 768px 断点三列 ↔ 单列 |

### 8.5 原型与真实实现的差异

| 项 | 原型 | 真实实现 |
|---|---|---|
| 数据 | 静态 mock（演示快照），零网络请求 | 腾讯财经接口经 Rust 后端抓取，3s/15s 轮询 |
| 图表 | 手绘内联 SVG（分时/K线两套绘制函数） | lightweight-charts v5 多 pane 布局 |
| 路由 | hash 模拟 SPA（`#/board`、`#/detail/{code}`） | Vue 状态切换两视图（无路由库） |
| 定位 | 评审视觉风格与交互流，随 PRD 归档 | 交付功能本体 |
