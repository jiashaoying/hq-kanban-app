# 大盘行情看板 构建与调试命令手册

**适用项目**：Tauri v2 + Vue 3（大盘行情看板）
**平台覆盖**：macOS 桌面 / iOS 模拟器 / iOS 真机
**更新日期**：2026-08-31

---

## 〇、环境前提

| 依赖 | 说明 |
|---|---|
| Rust 工具链 | 使用 rustup 的 cargo（Homebrew 版缺少 iOS target） |
| iOS targets | `rustup target add aarch64-apple-ios aarch64-apple-ios-sim` |
| xcodegen | 重新生成 Xcode 项目（`brew install xcodegen`） |
| pnpm | 前端包管理与脚本执行 |
| Xcode 26.5+ | 含 iOS SDK 与真机支持组件 |

**Rust 工具链 PATH（所有 cargo 命令前先 export）**：

```bash
export PATH="$HOME/.rustup/toolchains/stable-aarch64-apple-darwin/bin:$HOME/.cargo/bin:$PATH"
```

**查看连接的 iOS 设备 UDID**：

```bash
xcrun xctrace list devices
# 真机示例输出: 贾少英17PM (27.0) (00008150-000A31163407801C)
```

## 一、日常开发（macOS 桌面）

### 开发调试

```bash
# 开发模式：同时启动 Vite(localhost:1420) 与 Rust 后端，支持 HMR
pnpm tauri dev
```

### 发布构建

```bash
# 生产构建（类型检查 → Vite 构建 → Rust release 编译 → 打包）
pnpm tauri build
```

**产物位置**：

| 产物 | 路径 | 用途 |
|---|---|---|
| App | `src-tauri/target/release/bundle/macos/大盘行情看板.app` | 本机直接运行 / 拖入 Applications 安装 |
| DMG | `src-tauri/target/release/bundle/dmg/大盘行情看板_0.1.0_aarch64.dmg` | 分发给其他 macOS 用户 |

### 运行已构建的 App

```bash
# 直接启动构建产物
open src-tauri/target/release/bundle/macos/大盘行情看板.app

# 打开 DMG 所在目录（双击 dmg 拖入 Applications 完成安装）
open src-tauri/target/release/bundle/dmg/

# 查看产物信息
ls -la src-tauri/target/release/bundle/macos/
ls -la src-tauri/target/release/bundle/dmg/
```

> 桌面窗口为自定义标题栏（`decorations: false`），按住顶部标题栏可拖动窗口；CSP 已关闭（null），图标位于 `src-tauri/icons/`。

## 二、iOS 模拟器（调试）

```bash
# 方式一：Tauri CLI 一键运行（自动起 Vite + cargo + 模拟器）
pnpm tauri ios dev

# 方式二：手动构建（自定义构建流程时使用）
cd src-tauri/gen/apple
xcodegen generate                      # project.yml 有改动时必须执行

xcodebuild -project hq-kanban-app.xcodeproj \
  -scheme hq-kanban-app_iOS \
  -configuration debug \
  -destination 'platform=iOS Simulator,name=iPhone 17' build

# 安装并启动到模拟器
xcrun simctl install "iPhone 17" <DerivedData中debug-iphonesimulator的.app路径>
xcrun simctl launch "iPhone 17" com.huafu.hqkanbanapp
```

> 模拟器构建使用 `aarch64-apple-ios-sim` target，preBuildScript 会根据 `PLATFORM_DISPLAY_NAME` 自动切换。

## 三、iOS 真机（Release 构建 + 部署，推荐）

```bash
# 1. 构建前端产物
pnpm build

# 2. 清理 Rust release 缓存（feature/配置变更后必须）
export PATH="$HOME/.rustup/toolchains/stable-aarch64-apple-darwin/bin:$HOME/.cargo/bin:$PATH"
cd src-tauri
cargo clean --target aarch64-apple-ios --release

# 3. 重新生成 Xcode 项目（project.yml 有改动时必须）
cd gen/apple
xcodegen generate

# 3.1 验证构建脚本已同步（应输出含 --features tauri/custom-protocol）
grep -o "CARGO_FLAGS=[^;]*" hq-kanban-app.xcodeproj/project.pbxproj

# 4. xcodebuild 构建（preBuildScript 自动编译 Rust）
DEVICE_UDID="00008150-000A31163407801C"   # 替换为实际 UDID
xcodebuild -project hq-kanban-app.xcodeproj \
  -scheme hq-kanban-app_iOS \
  -configuration release \
  -destination "id=$DEVICE_UDID" \
  -allowProvisioningUpdates build

# 5. 验证 production 模式（关键！输出必须为 0）
strings src-tauri/gen/apple/Externals/arm64/release/libapp.a \
  | grep -c "local network permissions"

# 6. 安装并启动
APP="$HOME/Library/Developer/Xcode/DerivedData/hq-kanban-app-*/Build/Products/release-iphoneos/大盘行情看板.app"
xcrun devicectl device install app --device $DEVICE_UDID $APP
xcrun devicectl device process launch --device $DEVICE_UDID com.huafu.hqkanbanapp
```

## 四、iOS 真机（Debug 开发调试）

真机 debug 模式连接开发服务器时，`localhost` 指向设备自身，需改用 Mac 局域网 IP：

```bash
# 1. 查询 Mac 局域网 IP
ipconfig getifaddr en0

# 2. 临时覆盖 devUrl 启动（替换 192.168.x.x 为实际 IP）
pnpm tauri ios dev --config '{"build":{"devUrl":"http://192.168.x.x:1420"}}'

# 3. 首次运行设备会弹窗申请"本地网络"权限，须在
#    设置 > 隐私与安全性 > 本地网络 中允许本应用
```

## 六、验证与排查命令

### 6.1 代码签名验证

```bash
# 查看本机可用签名身份（对比 tauri.conf.json 的 developmentTeam）
security find-identity -v -p codesigning

# 查看已构建 app 的签名信息
codesign -dv <app路径>
# 关键字段: TeamIdentifier=QZ5VGE4SZ9, Identifier=com.huafu.hqkanbanapp
```

### 6.2 Tauri 构建（dev/production）模式验证

```bash
# production 模式判据：以下输出必须为 0
# 该字符串仅存在于 tauri dev 模式编译的 proxy_dev_request 错误分支
strings <libapp.a路径> | grep -c "local network permissions"

# 0 = production（使用打包前端资源）✅
# 1 = dev 模式（会连接 localhost:1420）❌ → 检查 custom-protocol feature
```

### 6.3 静态库与构建产物检查

```bash
# 确认 preBuildScript 中 feature 标志已同步到 pbxproj
grep -o "CARGO_FLAGS=[^;]*" src-tauri/gen/apple/hq-kanban-app.xcodeproj/project.pbxproj

# 确认 app bundle 中不含误打包的静态库
ls <app路径>/ | grep libapp.a    # 应无输出

# 查看 Rust 编译产物
ls -la src-tauri/target/aarch64-apple-ios/release/libhq_kanban_app_lib.a
```

### 6.4 设备与进程管理

```bash
# 列出设备
xcrun xctrace list devices

# 安装 / 启动 app
xcrun devicectl device install app --device <UDID> <app路径>
xcrun devicectl device process launch --device <UDID> com.huafu.hqkanbanapp

# 带控制台输出启动（查看崩溃日志，超时属正常，Ctrl+C 退出）
xcrun devicectl device process launch --console --device <UDID> com.huafu.hqkanbanapp

# 拉取设备系统崩溃报告（.ips，已符号化；--console 只给 signal 11 时用这个）
mkdir -p /tmp/ios-crash
xcrun devicectl device copy from --device <UDID> \
  --domain-type systemCrashLogs --source . --destination /tmp/ios-crash
ls -t /tmp/ios-crash/*.ips | head

# 导出 App 沙盒（含 Documents/tauri_panic.log）
xcrun devicectl device copy from --device <UDID> \
  --domain-type appDataContainer --domain-identifier com.huafu.hqkanbanapp \
  --source Documents --destination /tmp/ios-appdata

# 截图确认 UI 是否正常渲染（区分「闪退」与「黑屏」）
xcrun devicectl device capture screenshot --device <UDID> --destination /tmp/shot.png
```

### 6.5 常见问题速查

| 现象 | 排查命令 | 常见原因 |
|---|---|---|
| 启动即闪退（SIGTRAP/EXC_BREAKPOINT） | Xcode 附加调试看堆栈 | wry NSBundle 崩溃（已有 patch），确认 patch 生效 |
| 启动即闪退（SIGSEGV/EXC_BAD_ACCESS，栈顶 objc_retain） | `devicectl device copy from --domain-type systemCrashLogs` | 对象已释放被 retain；见 tao Scene 补丁 |
| dyld 阶段 EXC_BAD_ACCESS (0x0) | `ls <app>/ \| grep libapp.a` | 静态库误入 bundle；签名团队不匹配 |
| 安装失败 "No code signature found" | `codesign -dv <app>` | IPA 未签名（`--no-sign` 构建的 IPA 不可直接安装） |
| 安装失败 "Failed Registering Bundle Identifier" | 更换 Bundle ID | 该 ID 已被其他开发者账号注册 |
| 报 localhost:1420 错误 | `strings libapp.a \| grep -c "local network permissions"` | 结果为 1：custom-protocol 未生效；检查 pbxproj 是否同步、清缓存重建 |
| xcodebuild 报 "No Account for Team" | `security find-identity` | tauri.conf.json 的 developmentTeam 与本机账号不符 |
| 构建脚本改动不生效 | `grep CARGO_FLAGS project.pbxproj` | 忘记 `xcodegen generate` |

## 七、配置文件一致性清单

修改签名或 Bundle ID 时，以下位置必须保持一致：

| 文件 | 字段 | 当前值 |
|---|---|---|
| `src-tauri/tauri.conf.json` | `identifier` / `bundle.iOS.developmentTeam` | `com.huafu.hqkanbanapp` / `QZ5VGE4SZ9` |
| `src-tauri/gen/apple/project.yml` | `bundleIdPrefix` / `PRODUCT_BUNDLE_IDENTIFIER` / `DEVELOPMENT_TEAM` | `com.huafu.hqkanbanapp` / `com.huafu.hqkanbanapp` / `QZ5VGE4SZ9` |
| `src-tauri/gen/apple/hq-kanban-app.xcodeproj/project.pbxproj` | `PRODUCT_BUNDLE_IDENTIFIER` / `DEVELOPMENT_TEAM` | 由 xcodegen 从 project.yml 生成 |

> **黄金法则**：`project.yml` 是唯一事实来源。改 yml → `xcodegen generate` → `grep` 验证 pbxproj → `cargo clean` → 重新构建。
