- 组件统一使用 `<script setup lang="ts">` 语法并通过 `defineProps` / `defineEmits` 声明接口，类型来自 `../types/market.ts`。
- 业务状态与副作用集中在 `composables/` 中的组合式函数内（如 `useMarketData`），组件仅通过解构返回值消费数据与方法。
- 数值展示统一委托给 `utils/format.ts` 中的纯函数（`formatPrice`、`formatChange`、`formatVolume` 等），不在模板中直接调用 `toFixed`。
- 趋势视觉（颜色、背景、左边框）通过 `computed` 派生 `trend` / `trendColor` / `trendBg` / `trendBorder` 等响应式变量驱动 class 绑定。
- 市场分组通过 `computed` 对原始 `indices` 按 `market` 字段过滤重组为 `MarketGroup[]`，避免在模板中重复 filter。
