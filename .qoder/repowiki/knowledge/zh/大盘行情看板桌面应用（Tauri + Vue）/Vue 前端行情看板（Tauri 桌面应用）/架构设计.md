采用 Vue 3 `<script setup>` 单文件组件架构，入口 `main.ts` 通过 `createApp(App)` 挂载根组件；页面按职责拆分为 `components/`（`TitleBar.vue` 负责窗口拖拽/最小化/关闭等 Tauri 窗口控制、`MarketSection.vue` 按市场分组渲染、`IndexCard.vue` 展示单个指数卡片）、`composables/useMarketData.ts` 封装数据轮询逻辑（每 3 秒调用 `@tauri-apps/api/core` 的 `invoke('fetch_indices')` 拉取数据并计算 `marketGroups`）、`types/market.ts` 定义共享的 `IndexData` / `MarketGroup` 类型、`utils/format.ts` 提供价格/涨跌/成交量/成交额格式化函数。依赖方向单向：App → composables → types/utils，组件仅消费 props/computed，无跨组件状态共享，样式统一使用 Tailwind CSS 类名。
