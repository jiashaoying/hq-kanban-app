根目录作为 Tauri v2 应用的统一入口：`package.json` 中的 `tauri dev/build` 脚本同时驱动 Vite 开发服务器（固定端口 1420，HMR 走 1421）与 Rust 后端编译；`vite.config.ts` 通过 `TAURI_DEV_HOST` 环境变量把前端 dev server 接入 Tauri 的 WebView，并忽略 `src-tauri/` 避免重复监听。运行时前后端通过 Tauri 的 `invoke` 机制通信——前端 `useMarketData` composable 每 3 秒调用 `fetch_indices` 命令，Rust 端在 `lib.rs` 中用 `generate_handler!` 注册该命令并在 `market.rs` 中请求 `qt.gtimg.cn`、GBK 解码后返回 JSON。构建流程由根级 `pnpm tauri build` 串联：先执行 `vue-tsc --noEmit && vite build` 产出 `dist/`，再由 `src-tauri/build.rs` 打包进原生二进制，最终输出各平台的安装包。
